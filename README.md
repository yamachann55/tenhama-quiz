# 天浜線 文化財めぐり号 〇×クイズ システム

天竜浜名湖鉄道（旧国鉄二俣線）の登録有形文化財めぐりをテーマにした、スマートフォン縦画面専用のリアルタイム〇×クイズシステムです。
温かみのある**レトロベージュ基調（硬券切符・木造駅舎風）のデザイン**と、イベント現場での**誤タップ事故を100%防ぐ2段階操作UI**を搭載しています。

---

## 🌟 主な特徴

### 1. 誤タップ防止機構（現場仕様）
- **回答者側（乗客）**:
  - 〇・✕ボタンを押しただけでは送信されず、選択肢がハイライトされた後に「【〇】で解答を決定する」ボタンを押して初めて送信完了。
  - 管理者が正誤発表を行う前であれば、「選び直す」ボタンでいつでも解答を変更可能。
- **管理者側（運行司令）**:
  - 「次の問題」「前の問題」「正誤発表」「リセット」の全重要操作に**確認ダイアログ（モーダル）**を設置。うっかり指が触れて進行してしまう事故を防ぎます。

### 2. 最大45名対応・リアルタイム集計ダッシュボード
- 1両貸切ツアー（約40〜45名）を想定したリアルタイム集計。
- 現在の回答者数（〇と✕の内訳比率バーグラフ）。
- 正誤発表後は正答率（％）、正解者数、誤答者数を即時可視化。

### 3. 完全無料・選べる2つの稼働モード
1. **タブ間ローカル連携モード（即座にテスト可能）**:
   - サーバー不要。同一ブラウザで `player.html` と `admin.html` を開くだけで、`BroadcastChannel` によりラグ0秒で同期。
   - 管理者画面には「+10名」「45名満席」のダミー回答者シミュレーターを内蔵。
2. **Google Apps Script (GAS) モード（本番運用）**:
   - Googleアカウントだけで完全無料で動くWeb API。
   - Googleスプレッドシート上で問題文・正解・解説を誰でも手軽に編集可能。
   - `CacheService` を搭載し、45人の同時アクセスでも高速応答。

## 🚀 すぐにテストしてみる方法

1. `index.html`（または `player.html` と `admin.html`）をブラウザで開きます。
2. 管理者画面と回答者画面を画面の左右に並べて開きます。
3. 回答者画面で名前を入力して〇を選んで送信し、管理者画面の集計や操作ボタンの動きを体験してください！
