# Google Apps Script (GAS) 無料バックエンド セットアップ手順書

天浜線文化財めぐり号クイズのバックエンドとして、GoogleスプレッドシートとGASを連携させる手順です。
完全無料で利用でき、Googleアカウントが1つあれば数分で完了します。

---

## ステップ 1: Googleスプレッドシートの新規作成

1. ブラウザで [Googleスプレッドシート](https://sheets.new) を開きます。
2. スプレッドシートのタイトルを「**天浜線文化財めぐり号クイズ管理**」などに設定します。

---

## ステップ 2: Apps Script エディタを開く

1. スプレッドシート上部メニューの **[拡張機能]** → **[Apps Script]** をクリックします。
2. 開いたエディタ画面の `コード.gs` に、本フォルダの [`gas/Code.gs`](file:///d:/Yamachann55/%E5%A4%A9%E6%B5%9C%E7%B7%9A%E6%96%87%E5%8C%96%E8%B2%A1%E3%82%81%E3%81%90%E3%82%8A%E5%8F%B7%E3%82%AF%E3%82%A4%E3%82%BA/gas/Code.gs) の内容をすべてコピー＆ペーストして上書きします。
3. 💾 アイコン（保存）をクリックします。

---

## ステップ 3: 初期シートの自動セットアップ

1. エディタ上部の関数選択ドロップダウン（通常は `myFunction`）から **`setupSheets`** を選択します。
2. **[実行]** ボタンをクリックします。
3. 初回実行時、「承認が必要です」というポップアップが出ます：
   - **[権限を確認]** をクリック
   - 自分のGoogleアカウントを選択
   - 「Google ではこのアプリを検証していません」と出たら、左下の「**詳細**」をクリックし、「**無題のプロジェクト（安全ではないページ）に移動**」をクリック
   - 右下の「**許可**」をクリック
4. 実行が完了すると、スプレッドシート側に以下の3つのシートが自動生成されます：
   - `問題一覧`（問題番号、問題文、正解[O/X]、解説、そして**画像URL[任意]**の列が用意されます。画像のWebリンクを貼ると解説欄に相対幅90%で表示されます！）
   - `状態管理`（現在の問題番号やフェーズを記録）
   - `回答データ`（参加者の回答履歴を記録）

---

## ステップ 4: ウェブアプリとしてデプロイ

1. エディタ右上の青い **[デプロイ]** ボタン → **[新しいデプロイ]** をクリックします。
2. 左上の歯車アイコン（種類の選択）をクリックし、**[ウェブアプリ]** を選択します。
3. 設定項目を入力します：
   - **説明**: `v1` （任意）
   - **次のユーザーとして実行**: `自分 (あなたのメールアドレス)`
   - **アクセスできるユーザー**: **`全員`** （※必ず「全員」にしてください。ログイン不要で誰でも参加できるようにするためです）
4. **[デプロイ]** をクリックします。
5. 表示された **ウェブアプリのURL**（`https://script.google.com/macros/s/xxxx/exec`）をコピーします。

---

## ステップ 5: フロントエンドへのURL設定

1. 本プロジェクトの [`js/config.js`](file:///d:/Yamachann55/%E5%A4%A9%E6%B5%9C%E7%B7%9A%E6%96%87%E5%8C%96%E8%B2%A1%E3%82%81%E3%81%90%E3%82%8A%E5%8F%B7%E3%82%AF%E3%82%A4%E3%82%BA/js/config.js) を開きます。
2. `GAS_API_URL: ""` の部分に、コピーしたURLを貼り付けます：
   ```javascript
   const CONFIG = {
     GAS_API_URL: "https://script.google.com/macros/s/あなたのID/exec",
     ...
   };
   ```
3. これで全乗客のスマホと管理者画面がGASを通じて完全同期します！

---

## 45人アクセスへの工夫について
このスクリプトは `CacheService`（GASの高速インメモリキャッシュ）を使用しているため、45人が4〜5秒間隔で一斉に状態をチェックしても、Googleスプレッドシートへのアクセス集中を起こさず、ミリ秒単位で高速に応答します。

---

## 📷 Googleドライブの写真を問題に使う方法

Googleドライブに保存してある写真をスプレッドシートの「問題一覧」E列に貼るだけで表示できます！

1. Googleドライブに写真（JPEG/PNG等）をアップロードします。
2. 写真を右クリック → **[共有]** → **[共有]** を選択します。
3. **一般的なアクセス** を「制限付き」から **「リンクを知っている全員」**（閲覧者）に変更します。※ここがポイント！
4. **[リンクをコピー]** をクリックします。
5. コピーしたURL（例: `https://drive.google.com/file/d/xxxxxxx/view?usp=sharing`）を、スプレッドシートの **E列（画像URL）にそのままペースト** すれば完了です！
   - ※システム側で自動的にWeb表示用の最適化リンクに変換されるため、加工やIDの抜き出しは一切不要です！
